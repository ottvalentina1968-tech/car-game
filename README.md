# Машинки

Простая гонка в браузере: держись своей полосы и объезжай машины.

## Как играть

Открой `index.html` в браузере.

- Стрелки влево/вправо или `A` / `D` — смена полосы
- Пробел или клик — старт и рестарт
- На телефоне: тап слева или справа от центра

Счёт растёт, пока едешь. После столкновения рекорд сохраняется в браузере.
